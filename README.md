# Machine Learning Lab 01

This repository contains Python scripts for data exploration, preprocessing, and similarity measures on clinical datasets.

## 📁 Repository Structure

* **A1 - A3:** Matrix operations, linear systems, and vector modeling.
* **A4:** Data exploration (attribute types, ranges, missing values, and outliers).
* **A5:** Binary similarity measures (Jaccard Coefficient & Simple Matching Coefficient).
* **A6:** Vector-based Cosine Similarity measure.
* **A7:** Similarity matrix visualizations using heatmaps.
* **A8:** Missing value imputation strategies (Mean/Median/Mode).
* **A9:** Min-Max Feature Scaling and Normalization.
